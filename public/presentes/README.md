# Ícones dos presentes

Recortados do **infográfico neon criado pelo operador** (`presentes-originais/Infográfico Neon de Presentes em Corrida Ao Vivo.png`), com o fundo removido.

Não são as imagens oficiais do TikTok. Para usar a imagem oficial de um presente, envie-a em **Painel → PRESENTES DA CORRIDA → Trocar**.
